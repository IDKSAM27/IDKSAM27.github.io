# Service mark sources

The SVG files in this directory were copied at build time from the locally installed
[Simple Icons](https://simpleicons.org/) package. Simple Icons is a community-maintained
catalog of brand and project marks and releases its icon data under CC0 1.0. Individual
brands and projects retain their trademarks.

Included marks: Cloudflare, Docker, Grafana, Homepage, Immich, Jellyfin, Portainer,
PostgreSQL, Prometheus, qBittorrent, Radarr, Sonarr, and Uptime Kuma.

Where the catalog does not provide a legitimate project mark, the documentation renders
a text monogram rather than inventing or hotlinking a logo. Prometheus-family exporters
use the Prometheus mark, and cAdvisor uses the Docker mark as a small ecosystem identifier.

Last reviewed: 2026-08-03.
