# Engineering field notes

This collection extends the existing portfolio with operational documentation. It favors explicit current-state evidence, conservative engineering claims, and practical links between communicating systems.

## Provenance

- **Verified** statements come from supplied configuration, existing public portfolio material, or an explicit owner statement.
- **Inferred** statements come from upstream defaults or labeled representative hardware assumptions.
- **Proposed** statements describe recommendations, runbooks, or future work and do not claim that a control is currently deployed.

Private snapshots, credentials, logs, databases, and secret-bearing configuration values are excluded from public source and search indexes.
